# Computer Networks Lab

This repository contains programs and experiments for the **Computer Networks Laboratory**, covering basic networking concepts, socket programming, routing algorithms, and error detection techniques.

## TASKs
- TCP & UDP Socket Programming
- VLAN
- FTP HTTP SMTP
- DNS DHCP
- Subnetting
- SSH TELNET
- Routing Algorithms
- Packet Tracer Simulations

#### Tasks were performed using Cisco Packet Tracer (Optional)
